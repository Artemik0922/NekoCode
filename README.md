# NekoCode v0.4

**Код, который помнит свою архитектуру.** Claude Code аналог с блюпринтами, техдолгом, постоянной памятью и русским интерфейсом.

Локальный агент кода с красивым терминальным интерфейсом на Ollama. Не просто пишет код — документирует **ПОЧЕМУ** код написан так, отслеживает компромиссы, помнит вас между сессиями.

## Возможности v0.4

### 🎨 Красивый интерфейс (Rich)
Терминал с панелями, цветами, иконками и ASCII-артом кота.

### 🧠 Постоянная Память (Claude Code analog)
Файловая система памяти `.agent/memory/` с типами: `user`, `project`, `feedback`, `reference`. Сохраняется между сессиями. Команды: `remember`, `recall`, `/recall`.

### 📐 Архитектурные Блюпринты
ADR в `.agent/blueprints/*.json` — паттерн, область, обоснование, альтернативы, риски.

### ⚠️ Журнал Техдолга
`.tech-debt-log.md` с аудитом и разрешением. **Команды:** `/audit`, `/resolve <n>`.

### 🔧 Полный набор инструментов (Claude Code style)
`read`, `write`, `edit`, `glob`, `grep`, `bash`, `agent`, `task_create/update/done`, `submit_blueprint`, `log_tech_debt`, `remember`, `recall`.

### 🤖 Под-агенты
`explore` (только поиск), `plan` (архитектура), `general-purpose` (исследование), `worker` (автономное выполнение).

### 📋 Управление задачами
`task_create`, `task_update`, `task_done` для декомпозиции работы.

### 🧹 Защита контекста
Дедупликация read-запросов, авто-ограничение истории, сжатие контекста.

## Быстрый старт

```bash
ollama serve
ollama pull qwen3.5:4b

pip install rich
nekocode
```

## Параметры CLI

```bash
nekocode --cwd ~/my-project --model qwen3.5:4b --approval auto
```

| Флаг | По умолч. | Описание |
|------|-----------|----------|
| `--cwd` | `.` | Рабочая директория |
| `--model` | `qwen3.5:4b` | Модель Ollama |
| `--host` | `http://127.0.0.1:11434` | URL Ollama |
| `--approval` | `ask` | `ask` / `auto` / `never` |
| `--max-steps` | `8` | Макс. итераций на запрос |
| `--max-new-tokens` | `1024` | Макс. токенов |
| `--resume` | — | Возобновить сессию |
| `--temperature` | `0.2` | Температура модели |

## Команды

| Команда | Описание |
|---------|----------|
| `/help` | Показать справку |
| `/memory` | Память сессии |
| `/blueprints` | Список блюпринтов |
| `/audit` | Аудит техдолга |
| `/resolve <n>` | Закрыть долг |
| `/recall` | Постоянная память |
| `/task` | Список задач |
| `/session` | Путь к файлу сессии |
| `/reset` | Сбросить сессию |
| `/exit` | Выйти |

## Инструменты модели

| Инструмент | Риск | Описание |
|-----------|------|----------|
| `read` | нет | Чтение файла |
| `write` | да | Запись файла |
| `edit` | да | Замена текста |
| `glob` | нет | Поиск файлов |
| `grep` | нет | Поиск в содержимом |
| `bash` | да | Запуск команд |
| `agent` | нет | Делегирование под-агенту |
| `task_create/update/done` | нет | Управление задачами |
| `submit_blueprint` | нет | ADR |
| `log_tech_debt` | нет | Техдолг |
| `remember/recall` | нет | Постоянная память |
