# NekoCode

**Код, который помнит свою архитектуру.**

Локальный агент для написания кода с красивым терминальным интерфейсом. Он не просто пишет код — он документирует **ПОЧЕМУ** код написан так, и отслеживает компромиссы.

## Возможности

### 🎨 Красивый интерфейс
Терминал с панелями, цветами, иконками и ASCII-артом.

### 📐 Архитектурные Блюпринты
Перед написанием нетривиального кода агент записывает Архитектурное Решение (ADR):

```
📐 Блюпринт: Repository Pattern
  Область:   слой доступа к данным
  Зачем:     разделение ответственности, удобство тестирования
  Вместо:    Active Record
  Риски:     лишняя абстракция для простых запросов
```

Сохраняется в `.agent/blueprints/*.json` для аудита.

### ⚠️ Журнал Техдолга
Каждый компромисс логируется в `.tech-debt-log.md`:

```
| Дата | Файл | Долг | Причина | Статус |
| 2026-07-29 | binary_search.py | Пропущена валидация | дедлайн демо | открыт |
```

**Команды:** `/audit`, `/resolve <n>`

### 🧠 Рабочая Память
Агент помнит задачу, затронутые файлы, блюпринты и заметки. Смотреть — `/memory`.

## Параметры CLI

```bash
nekocode --cwd ~/my-project --model qwen3.5:4b
```

| Флаг | По умолч. | Описание |
|------|-----------|----------|
| `--cwd` | `.` | Рабочая директория |
| `--model` | `qwen3.5:4b` | Модель Ollama |
| `--approval` | `ask` | `ask` / `auto` / `never` |
| `--max-steps` | `6` | Макс. итераций |
| `--resume` | — | Возобновить сессию |

## Команды

| Команда | Описание |
|---------|----------|
| `/help` | Показать справку |
| `/memory` | Рабочая память |
| `/blueprints` | Список блюпринтов |
| `/audit` | Аудит техдолга |
| `/resolve <n>` | Закрыть долг |
| `/session` | Путь к файлу сессии |
| `/reset` | Сбросить сессию |
| `/exit` | Выйти |
